Import Products
Upload a CSV or Excel (.xlsx) file to bulk-import products. This is useful when migrating from another POS system or adding products in bulk.
Required CSV Format
Name, Barcode, Category, CostPrice, SellingPrice, Quantity
Required columns: Name, SellingPrice
Optional columns: Barcode, Category, CostPrice, Quantity
How it works: The first row must be column headers. Each subsequent row creates one product. Products with duplicate barcodes (already in the system or repeated in the file) are skipped. Quantity is assigned to your current branch — all other branches start at 0. You can upload product images individually after import.
